# Achievement Manager v0.8.0-beta.4 — 公開前修正版

## 修正点
- 実績管理タブの左側に既存の基本実績を `[基本]` として表示。v0.8で追加した実績は `[追加]` として表示。
- 基本実績を選択すると **実績名・★ランク・達成回数** を編集可能。基本実績の特殊なイベント判定（ハテナ、挨拶、複合ハッキングなど）は誤動作防止のため変更不可。
- 追加実績は従来どおりイベント種別・キーワード・複数条件などを編集可能。
- 実績管理に **削除** ボタンを追加。確認ダイアログの後、実績一覧・カード・今後の解除判定から除外。
- 削除は**履歴を守る論理削除**です。DB内の実績定義・進捗・解除履歴は残ります。アプリ内に削除の取り消し機能はありません。
- 基本実績の変更をアプリ起動時に初期値で上書きしないように修正。
- TKG未接続時は共通の基本実績だけ表示。TKG受付中はTKG専用実績も編集可能。
- Twitch PKCE自動ログイン、OBS通知、解除済み強調表示、★並び替えを維持。

## 更新手順
1. `%LOCALAPPDATA%\AchievementManager\achievements.db` をバックアップ。
2. ZIPの中身を `develop-v0.8` にアップロード・コミット。
3. GitHub Actions → `Windows v0.8 Beta installer` → 最新のビルド結果からArtifactをダウンロード。
4. `AchievementManager-Setup-v0.8.0-beta.4.exe` をWindowsでインストールして実績編集・削除を確認。
5. 問題なければGitHub Releasesで `v0.8.0-beta.4` を **Pre-release** 公開。
