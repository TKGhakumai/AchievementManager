# Achievement Manager v0.8.0-beta.3 公開候補

## 変更点
- 初期表示はTwitch共通の実績9件。従来のTKG固有実績22件はTKG連携受付を有効にするまで「実績一覧」「個人実績カード」から非表示。
- 「設定・接続」→「TKG接続」でローカル連携の受付を有効にするとTKG専用実績を表示。「TKG切断」で再び非表示。
- v0.8で作成された `source=tkg_template` の実績も同じ表示制御。
- 旧実績のID・解除済み履歴・進捗は削除せず保持。切断しても進捗はリセットされない。
- TwitchのPKCE自動ログイン、解除済み強調表示、★昇降順、カスタム実績、OBS通知を維持。
- TKG本体のソースや素材は同梱しません。TKG本体側のイベント送信処理は別途必要。

## 重要な仕様
TKG接続ボタンは、現時点では**ローカル受信サーバーの受付開始**です。TKG本体と通信が成立したことを検出するハンドシェイク完了表示ではありません。
従来の31実績はDB互換性のため内部で保持し、画面上だけ9件と22件に分けます。
既存のイベントログに残る過去の解除履歴は、履歴保護のため自動削除しません。

## ビルド
GitHubの `develop-v0.8` にZIPの中身をアップロードしてください。
GitHub Actions → `Windows v0.8 Beta installer` → Run workflow。
インストーラー予定名: `AchievementManager-Setup-v0.8.0-beta.3.exe`。

## 公開前の確認
1. v0.7またはv0.8のSQLiteデータベースをバックアップ。
2. TKG未接続で実績一覧・個人実績カードに共通9件のみ表示されることを確認。
3. TKG接続で専用22件が表示され、切断で非表示に戻ることを確認。
4. TKG実績の解除済み状態が接続の前後で保持されることを確認。
5. Twitch自動ログイン、コメント・スタンプ判定、OBS通知、EXEインストールと上書き更新をWindowsで確認。
6. 問題がなければ GitHub Releases でタグ `v0.8.0-beta.3` を作成し、**Pre-release**としてインストーラーを添付。
