# Achievement Manager v0.8.0-beta.6 — 確認ありの自動アップデート

## 今回の変更
- アプリ起動約2.5秒後に、バックグラウンドでGitHub Releasesの公開済みリリースを確認。
- Beta版も対象。`/releases/latest`ではなく`/releases?per_page=30`を使用し、プレリリースも取得。
- バージョン番号を比較し、**現在より新しいものだけ**表示。Draftは無視。
- 更新があればユーザーにダウンロード確認 → GitHub Releasesからインストーラーをダウンロード。
- 公開アセットのSHA256ダイジェストが提供されている場合は検証し、常にファイルサイズとEXEヘッダーを確認。
- ダウンロード後、もう一度インストール確認。承認時のみSQLiteのオンラインバックアップを作成し、インストーラーを起動してアプリを終了。
- 「設定・接続」→「今すぐ更新を確認」で手動確認も可能。
- オフラインでもアプリを利用可能。自動チェックの通信エラーは起動を妨げない。
- 既存の実績編集・削除、セッションログ、12時間NEW、Twitch PKCE、TKG任意連携、OBS通知は維持。

## データの保護
- 実績DBは`%LOCALAPPDATA%\AchievementManager\achievements.db`に保存され、インストーラーのアプリ本体とは別の場所です。
- インストール直前に`achievements_pre_update_YYYYMMDD_HHMMSS.db`を同じフォルダーに作成。
- アップデート時に実績DB・解除履歴・個人実績カードの情報を削除しません。
- 既存のアプリと同じInno Setup AppIdとインストール先を使用。
- 編集画面に未保存変更がある場合、インストーラーの起動を中止。

## ユーザーに見える動作
1. アプリ起動後、新しいReleaseがあれば更新案内。
2. 「はい」でインストーラーをダウンロード。「いいえ」で後回し。
3. ダウンロード完了後、インストールするか再確認。
4. 「はい」でデータバックアップ→Windowsインストーラー起動→アプリ終了。
5. インストーラーの案内に従い上書きインストール。

**更新の自動確認・ダウンロードは自動インストールではありません。** ユーザーの同意なしにインストーラーを起動しません。

## ビルドと公開
1. このZIPの中身を`develop-v0.8`にアップロード。
2. GitHub Actions `Windows v0.8 Beta installer` の成功を確認。
3. `AchievementManager-Setup-v0.8.0-beta.6.exe` をWindowsでインストール。
4. GitHub Releasesでタグ`v0.8.0-beta.6`をTarget=`develop-v0.8`で作成し、**Pre-release**で公開。
5. beta.6での更新確認を試すには、beta.7など**beta.6より新しい**テスト用リリースが必要。公開前のテストはローカルモックで実施済み。

## 注意事項
- この機能は**beta.6をインストールしたユーザー以降**に有効。既存のbeta.4/beta.5には機能がないため、beta.6への最初の更新は手動。
- インストーラーのコード署名は未対応。Windows SmartScreenの警告が出る場合があります。
- GitHub Releases APIの公開済みリリース最大30件を対象とします。
- GitHub APIの障害・制限時は更新確認できないことがあります。
- 自動ダウンロードのファイルはOSの一時フォルダーに保存されます。
- SHA256がGitHub APIから提供されない場合、SHA256の照合はスキップします（サイズとEXE形式は検査）。
- WindowsのEXE起動・Inno Setup上書き動作・Twitch/OBS連携はこの環境では未検証です。
