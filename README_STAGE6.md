# Achievement Manager v0.8 — Stage 6（開発・検証版）

## 変更内容
- Stage 5の起動時エラー `AttributeError: card_rank_order` を根本修正。個人実績カードの★昇順/降順セレクターを画面構築時に生成。
- 個人実績カードの「ランク」見出しクリックでも並び替え可能。追加・編集後も選択順を維持。
- ダッシュボードの「最近の実績解除」にv0.8カスタム実績も表示。従来のv0.6実績も維持。
- 「チャット本文でテスト」追加。実際のチャット解析関数（コメント・キーワード・挨拶など）をローカルで通し、進捗と解除を検証できる。
- テストイベントの記録・解除結果をダッシュボードに表示。
- ブリッジの受信ステータス文字列処理を修正。
- 解除時のOBSブラウザ通知とデスクトップ通知の既存処理を維持。

## 確認方法
1. アプリを閉じて `%LOCALAPPDATA%\AchievementManager\achievements.db` をバックアップ。
2. ZIP内の `main.py`、`achievement_editor.py`、`achievement_core/` をdevelop-v0.8へ上書き。
3. `python main.py` で起動。個人実績カードの★昇順/降順を確認。
4. 「実績管理」で「キーワード：こんにちは、1回」等のカスタム実績を作成。
5. ダッシュボードでテストIDを設定し、「チャット本文」に「こんにちは」を入力して「チャット本文でテスト」をクリック。
6. 実績一覧・個人実績カード・最近の解除履歴とOBSブラウザソース（`http://127.0.0.1:8766/`）を確認。

## 既知の制限
- Twitch IRCライブ接続とOBSのWindows実機表示は、この環境では未検証。
- チャネポEventSub自動受信、TKG任意接続は未実装。
- 「チャット本文でテスト」はTwitchのemotesタグを伴わないため、Twitch公式スタンプ検出は実際のIRC受信で確認する必要がある。
- 既存の実績と進捗を初期化しない。テスト実績は本番DBに記録されるため、テスト用ユーザーIDを使うこと。
